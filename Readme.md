# MERN Stack E-Commerce Platform

A full-stack e-commerce web application built using the MERN stack.  
This project includes product browsing, cart management, order functionality, reviews system, authentication, and responsive user interface.

# API Functionalities

## Cart API
- Add products to cart
- Delete cart items
- Fetch user cart data

## Orders API
- Store order information
- Fetch orders by user email
- Sort latest orders

## Reviews API
- Fetch reviews by product ID
- Sort reviews by latest date
